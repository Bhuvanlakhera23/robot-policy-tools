# Independent implementation and owner release boundary

New source was written for Portfolio V5 from ordinary data schemas, affine action
mapping and generic sampled-signal mathematical definitions. No protected robot
implementation, history packing, temporal encoder, training/evaluation module,
model, transport, private simulator asset or unpublished log was read or extracted
for this package. No third-party source is vendored. The Python standard library
and development tools retain their own licenses.

The independent root Git history begins with this new package. It was not used
to generate earlier published locomotion benchmarks. The example is deterministic
synthetic data and makes no robot-performance claim.

Name: `robot-policy-tools` is provisional and descriptive, not an endorsement or
claim of affiliation. An initial exact-name search did not identify an obvious
same-name project; registry availability/trademark clearance is unestablished.
Do not upload under this name without owner review.
